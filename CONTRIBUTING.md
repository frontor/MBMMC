# Contributing

Changes that may affect published results must document the scientific rationale,
update tests and documentation, and state whether outputs differ from the paper
release. Never rewrite the commit or release cited by the manuscript.

Do not submit patient-level data, credentials, or restricted artifacts.


## Contribution licensing

Contributions accepted into MBMMC are expected to be distributable under the
PolyForm Noncommercial License 1.0.0. Contributors must have the right to submit
their code and must disclose copied, adapted, or generated third-party material.

Before accepting substantial external contributions, the maintainers should decide
whether a contributor license agreement is needed to preserve the ability to change
the license in future releases. Submission of a pull request alone should not be
treated as unrestricted relicensing permission.
